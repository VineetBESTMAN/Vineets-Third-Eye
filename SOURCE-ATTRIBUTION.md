A fresh Git history changes repository organization; it does not change who authored the inherited code.

Historical upstream issue/PR links and contributor credits in changelogs, archived development notes and dataset/media attribution identify the actual source of those contributions. They are not links for reporting issues or installing the current product; use this repository's README and issue tracker for those tasks.

Product branding, Windows launchers, local validation, standalone repository organization and subsequent changes are developed for Vineet's Third Eye. The current maintainer and product branding do not imply that all inherited code or third-party data was newly created for this edition.
